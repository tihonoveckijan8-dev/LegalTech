# Supabase для LegalFlow

На данный момент приложение не подключено к базе. Доступный подключённый Supabase-проект с именем groupp относится к другому продукту и не используется.

## Подключение нового проекта

Перед созданием проекта нужно подтвердить регион хранения данных с учётом будущих клиентов и применимых требований к персональным данным. Не подключайте базу другого приложения.

После создания отдельного проекта LegalFlow:

1. Установите Node.js 22.12+.
2. Инициализируйте локальную конфигурацию CLI:

   ~~~bash
   npx --yes supabase@2.122.1 init
   ~~~

3. Создайте файл миграции штатной командой CLI:

   ~~~bash
   npx --yes supabase@2.122.1 migration new initial_schema
   ~~~

4. Заполните миграцию согласованной схемой из docs/DATA_MODEL.md.
5. Проверьте grants, RLS и Storage policies до подключения пользовательского интерфейса.
6. Сгенерируйте TypeScript-типы базы через Supabase CLI после применения миграции.

## Важные правила безопасности

- В браузере используется только publishable key.
- Нельзя помещать secret/service_role key в переменные с префиксом VITE_.
- Ни одна таблица с данными компании не должна оставаться без RLS.
- Не используйте публичный Storage bucket для договоров.
- Авторизация не должна опираться на редактируемые пользователем поля профиля.
- Не применяйте миграцию к существующему проекту, пока не проверены его назначение и содержимое.
