# LegalFlow

**LegalFlow** — SaaS для управления договорным циклом компании: от заявки и проверки до утверждения, подписанного экземпляра и контроля обязательств.

Этот репозиторий перезапущен на согласованном стеке. Текущий код — чистая техническая основа и интерфейсная оболочка, а не готовая система для реальных договоров.

## Технологии

- React 19
- TypeScript 5.9
- Vite 8
- Supabase: PostgreSQL, Auth, Storage и Edge Functions
- Vitest для модульных тестов
- GitHub Actions для проверок

Версии прямых зависимостей зафиксированы в package.json. После первой установки npm создаст package-lock.json; его нужно сохранить в Git, чтобы зафиксировать и транзитивные зависимости.

## Локальный запуск

Требуется Node.js 22.12 или новее.

~~~bash
npm install
cp .env.example .env.local
npm run dev
~~~

Пока переменные Supabase пустые, приложение запускается в ознакомительном режиме без серверных данных. Чтобы подключить базу, заполните в .env.local:

- VITE_SUPABASE_URL
- VITE_SUPABASE_PUBLISHABLE_KEY

Используйте только publishable key. Secret/service_role key нельзя передавать в браузер.

## Проверки

~~~bash
npm run typecheck
npm test
npm run build
~~~

## Структура

- src/app — оболочка приложения и страницы.
- src/components — общие UI-компоненты.
- src/lib/supabase — безопасная инициализация клиентского SDK.
- docs/ARCHITECTURE.md — архитектурные решения.
- docs/DATA_MODEL.md — проектная модель данных.
- supabase/README.md — порядок настройки отдельного Supabase-проекта.
- .github/workflows/ci.yml — проверки в GitHub Actions.

## Что намеренно пока не подключено

- Supabase Auth и пользовательские сессии.
- Реальная база данных и миграции.
- Загрузка договорных файлов.
- Настоящие роли и разграничение доступа.
- Электронная подпись, 1С, AI и автоматические юридические заключения.

Это сознательный порядок реализации: сначала отдельный backend, схема данных, RLS и безопасность, затем рабочие функции. Старые демонстрационные договоры и localStorage-хранилище удалены из текущей версии.

## Продуктовый принцип

LegalFlow помогает понять, где находится договор, кто отвечает за следующий шаг, какие решения ожидаются и какие сроки приближаются. Сервис организует процесс, но не заменяет юриста, бухгалтера или юридически значимую подпись.
