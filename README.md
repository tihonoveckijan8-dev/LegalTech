# LegalFlow — MVP

Первый интерактивный прототип SaaS для управления договорными процессами компании.

## Запуск

Откройте `index.html` в современном браузере. Сборка и сервер пока не требуются.

## Что уже работает

- обзор с показателями по договорам и блоком задач, требующих внимания;
- реестр договоров с поиском и фильтрами по статусу и типу;
- создание карточки договора;
- карточка с контрагентом, суммой, ответственными, датой окончания и комментарием;
- демонстрационный маршрут: черновик → проверка юриста → проверка бухгалтера → утверждение директора → подписан;
- действия на этапах согласования в зависимости от выбранной демонстрационной роли;
- журнал действий и сохранение данных в браузере через localStorage;
- разделы «Согласования» и «Сроки и задачи»;
- адаптивная раскладка для мобильного экрана.

## Демонстрационные данные

При первом открытии загружаются вымышленные примеры договоров компании «Альфа Трейд». Созданные и изменённые записи сохраняются в localStorage текущего браузера. Очистка данных сайта сбросит демонстрацию к исходным примерам.

## Важные ограничения текущего MVP

Это front-end прототип для проверки пользовательского сценария, а не готовая система для реальных юридических документов.

- Нет регистрации и входа пользователей.
- Нет серверной базы данных и синхронизации между сотрудниками.
- Переключатель ролей демонстрирует сценарии, но не является защитой доступа.
- Файлы договоров пока не загружаются и не хранятся.
- Нет электронной подписи, интеграции с 1С или юридической проверки документов.
- Данные в браузере не следует использовать для хранения реальных договоров или персональных данных.

## Следующие этапы

1. Проверить сценарий с директорами, юристами, бухгалтерами и менеджерами нескольких компаний.
2. Уточнить реальные поля карточки, этапы согласования и права на действия.
3. Спроектировать backend, авторизацию, изоляцию организаций, разграничение доступа и аудит.
4. Добавить безопасное файловое хранилище, версии документов и уведомления.
5. Провести тестирование безопасности и правовой модели до использования реальных данных.

## Принцип продукта

LegalFlow помогает компании видеть, где находится каждый договор, кто отвечает за следующий шаг, какие решения ожидаются и какие сроки приближаются. Сервис организует процесс, но не заменяет юриста, бухгалтера или юридически значимую подпись.
